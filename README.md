# Ben Brahim Marbre - Marble E-Commerce Platform

Professional React + Vite web application for Ben Brahim Marbre, a premium marble and stone products supplier in Morocco.

## Features

✨ **Modern Architecture**
- Component-based React structure with separation of concerns
- Modular styling with CSS variables and best practices
- Responsive design for all screen sizes (mobile-first approach)
- Performance-optimized with code splitting

🎨 **Professional Design**
- Clean, modern UI with subtle shadows and smooth animations
- High-quality image handling with proper object-fit
- Accessible color contrast and typography
- Smooth scroll behavior and interactive elements

📱 **Responsive & Mobile-Friendly**
- Fully responsive across all devices
- Touch-friendly navigation and buttons
- Optimized for mobile, tablet, and desktop viewing
- Mobile navigation fallbacks

## Getting Started

### Prerequisites
- Node.js 18+ 
- npm 9+

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Development Guidelines

### Component Structure
Each component should be self-contained with its own styling and logic. Keep components focused on a single responsibility.

### Styling
- Use CSS variables for consistent theming
- Follow mobile-first approach in media queries
- Use CSS Grid and Flexbox for layout
- Keep shadow values consistent

### Image Optimization
- Use appropriate image formats (JPG for photos)
- Optimize images before adding to assets
- Use object-fit for consistent image sizing
- Implement lazy loading where appropriate
